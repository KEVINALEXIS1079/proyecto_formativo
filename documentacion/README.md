# Documentación del Proyecto - PDFs de Diseño

Esta carpeta contiene los documentos formales de diseño y especificación del proyecto Agrotech.

## 📄 Documentos Disponibles

### 1. **Acta de Requerimientos** (`ActaRequerimientos.pdf`)
Documento oficial que registra los requerimientos iniciales del sistema, acordados con los stakeholders del proyecto. Incluye:
- Objetivos del sistema
- Alcance del proyecto
- Requerimientos funcionales y no funcionales
- Firmas y aprobaciones

### 2. **Documento de Diseño UML** (`DocumentoDeDiseñoUML (1).pdf`)
Especificación técnica del diseño del sistema utilizando diagramas UML:
- Diagrama de Casos de Uso
- Diagrama de Clases
- Diagrama de Secuencia
- Diagrama de Componentes
- Diagrama Entidad-Relación (Base de Datos)
- Arquitectura del Sistema

### 3. **Especificación de Requisitos de Software** (`EspecificaciónDeRequisitosDeSoftware1.pdf`)
Documento detallado siguiendo el estándar IEEE 830 que especifica:
- Requisitos funcionales detallados por módulo
- Requisitos no funcionales (rendimiento, seguridad, usabilidad)
- Interfaces del sistema
- Restricciones de diseño
- Casos de uso expandidos

### 4. **Planteamiento del Problema** (`PlanteamientoDelProblema.pdf`)
Documento inicial que describe:
- Contexto y justificación del proyecto
- Problemática identificada
- Objetivos generales y específicos
- Beneficios esperados
- Alcance y limitaciones

## 🎯 Propósito

Estos documentos sirven como:
- **Referencia técnica** para el equipo de desarrollo
- **Documentación formal** para evaluación académica
- **Guía de implementación** para mantener la coherencia con el diseño original
- **Material de consulta** para futuras mejoras y mantenimiento
